# Basic Network Connectivity Lab

## Objective

Understand how devices communicate within a network and how ARP, DHCP, DNS, ICMP, and default gateways participate in network communication.

## Topology

PC1
|
Switch
|
Router
|
Internet

## Components

- 1 Client Device
- 1 Layer 2 Switch
- 1 Router
- DNS Service
- DHCP Service

## Protocols

- ARP
- DHCP
- DNS
- ICMP
- IPv4

## Validation Tests

- ipconfig
- ping gateway
- ping remote host
- ping domain name
- tracert
